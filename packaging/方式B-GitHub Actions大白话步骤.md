# 方式 B 大白话步骤：用 GitHub 免费帮你打包 exe（本机什么都不用装）

原理一句话：GitHub 提供免费的云端 Windows 电脑（叫 Actions），你把打包工程传上去，
它在云端替你把安装包打好，你再下载回来。下面每一步照着做就行。

## 第 0 步：准备

1. 你需要一个 GitHub 账号。没有就去 https://github.com 注册一个（免费，用邮箱注册，和注册普通网站一样）。
2. 下载 Muse 给你的打包工程压缩包 `ai-pm-coach-packaging.zip`，在电脑上解压。
   解压后会得到一个文件夹，名字叫 `ai-pm-coach-packaging`。
   **先打开这个文件夹看一眼**，记住里面长什么样（有 dist、src-tauri、package.json 等），下一步要用。

## 第 1 步：在 GitHub 上新建一个“仓库”

“仓库”就是 GitHub 上放一个项目的地方，你就当它是一个网上的文件夹。

1. 登录 GitHub，点页面右上角的 **+** 号，选 **New repository**（新建仓库）。
2. **Repository name**（仓库名字）随便起，比如就叫 `ai-pm-coach-app`。
3. 下面选 **Private**（私有，别人看不见）就行；选 Public（公开）也可以，看你喜好。私有仓库的免费打包时长也够用很多次。
4. 其他选项都不用动，点最下面的绿色按钮 **Create repository**（创建仓库）。

## 第 2 步：把工程文件传上去（最容易出错的一步，看仔细）

1. 打开刚建好的仓库页面，点页面中间的 **uploading an existing file**（上传已有文件）这行小字链接。
   （如果没看到这行字：点绿色的 **Code** 按钮附近找 **Add file** → **Upload files**，是同一个入口。）
2. 打开你电脑上解压出来的 `ai-pm-coach-packaging` 文件夹，**进入文件夹里面**，
   把里面的**全部内容**（所有文件和文件夹，包括那个看不见全名的 `.github` 文件夹）全选，
   拖到浏览器上传页面里，松手，等它传完（会显示进度）。
3. ⚠️ **千万注意**：要传的是“文件夹里面的东西”，不是把 `ai-pm-coach-packaging` 这个文件夹整个拖上去。
   传对了的标准：上传完回到仓库首页，能直接看到 `.github`、`src-tauri`、`dist`、`package.json` 这些名字排在列表里。
   如果你看到的是列表里只有一个 `ai-pm-coach-packaging` 文件夹，那就是套娃了，传错了——需要删掉仓库重来，或者把文件挪到外层。
4. 传完后，拉到页面最下面，点绿色按钮 **Commit changes**（提交更改）。

## 第 3 步：让 GitHub 开始打包

1. 点仓库页面上方的 **Actions** 标签页（在 Code 旁边）。
2. 这时候分两种情况：
   - 如果页面里已经有一条叫 **build-windows** 的记录在转圈（黄色）——说明它已经自动开始打包了，什么都不用点，跳到第 4 步等结果。
   - 如果没有在跑：点页面左侧的 **build-windows**，再点右边的 **Run workflow**（运行工作流）按钮，弹出的小框里再点一次绿色的 **Run workflow** 确认。
3. 如果 Actions 页里根本找不到 build-windows，或者提示 Actions 没启用：
   多半是第 2 步传错了层级（`.github` 没在最外层）。先回仓库首页检查能不能看到 `.github` 文件夹。

## 第 4 步：等它打完

- 打包一般要 **10–20 分钟**（第一次会久一点）。你可以关掉页面去忙别的，好了它也不会通知你，自己回来看。
- 回到 Actions 页看那条 build-windows 记录：
  - **绿色对勾 ✅** = 打包成功。
  - **红色叉 ❌** = 打包失败。点进去，把红色的那几行截图发给 Muse，它来判断问题。

## 第 5 步：把 exe 下载回来

1. 点那条成功的（绿勾）build-windows 记录，进入详情页。
2. 把页面拉到最下面，有一块叫 **Artifacts**（构建产物），里面有一项叫 **AI-PM-Coach-Windows**，点它下载。
3. 下载下来的是一个 zip，解压，里面就是安装包：**`AI PM Coach_0.1.0_x64-setup.exe`**。

## 第 6 步：装上、试一遍、把结果告诉 Muse

1. 双击这个 exe，按提示装完（如果电脑里没有 WebView2，它会自己顺带装上，不需要你另外找）。
2. 打开 AI PM Coach，随便走一遍：开始测评 → 答完 18 题 → 看结果 → 进学习页看看 → 关掉程序再打开一次，看看刚才的记录还在不在。
3. 再拔掉网线（或断开 Wi-Fi）打开一次，确认断网也能正常用。
4. 把结果告诉 Muse：一切正常，或者哪一步不对（带截图最好）。后面的全面测试由 Muse 继续完成。

## 常见问题

- **上传时找不到 `.github` 文件夹？** 它是隐藏风格命名的文件夹。在 Windows 资源管理器里点「查看」→ 勾选「隐藏的项目」，就能看见它了；全选时别漏掉它，没有它就不会自动打包。
- **仓库要花钱吗？** 不用。私有仓库每月有免费额度，足够打很多次包。
- **以后改了代码想重新打包怎么办？** 把新文件再传一次覆盖，或者点 Run workflow 再跑一次，就会重新出一个新的 exe。
